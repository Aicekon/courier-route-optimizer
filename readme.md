# 🚚 Оптимизатор маршрутов курьеров

Приложение на Python с графическим интерфейсом для автоматического распределения адресов доставки между курьерами и построения оптимальных маршрутов.

## 📌 О проекте

Программа решает прикладную задачу логистики: **как развезти список адресов силами нескольких курьеров за минимальное время**.

Что делает приложение:

1. Принимает список адресов и список курьеров через GUI (tkinter).
2. Автоматически получает координаты каждого адреса через Яндекс.Карты (Selenium).
3. Кластеризует адреса по количеству курьеров с помощью KMeans.
4. Внутри каждого кластера строит маршрут методом ближайшего соседа.
5. Запрашивает реальное время и расстояние маршрута через Яндекс.Карты.
6. Отображает итоговые маршруты по каждому курьеру.
7. Кэширует координаты и маршруты в `route_cache.pkl`, чтобы не дёргать Яндекс повторно.
8. Сохраняет состояние (адреса, курьеры, настройки) в `data.json`.

## ⚙️ Установка

### Требования

- **Python 3.10+**
- **Google Chrome** (последняя версия)
- **ChromeDriver**, соответствующий версии Chrome
- **tkinter** (обычно идёт в комплекте с Python; на Windows — галочка «tcl/tk and IDLE» при установке)

### Шаги

```bash
# 1. Клонировать репозиторий
git clone https://github.com/USERNAME/route-optimizer.git
cd route-optimizer

# 2. Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

# 3. Установить зависимости
pip install -r requirements.txt
```

### ChromeDriver

Скачай драйвер с [chromedriver.chromium.org](https://chromedriver.chromium.org/downloads) — версия должна совпадать с установленным Chrome.

Положи `chromedriver.exe` в **корень проекта** или добавь его в `PATH`.

## 📖 Использование

1. Добавь адреса в блоке **📬 Адреса** (например, `ул. Баумана, 5`).
2. Добавь курьеров в блоке **🚚 Курьеры** (двойной клик — переименовать).
3. При необходимости открой **⚙ Настройки** и укажи стартовые координаты и город.
4. Нажми **🚀 Начать расчет**.
5. Дождись результата — маршруты появятся в блоке **📊 Результаты**.

При закрытии окна данные сохраняются в `data.json`.

## ⚠️ Возможные проблемы

### `ModuleNotFoundError: No module named 'route_calculator'`
Запускай `main.py` из корня проекта. Если работаешь в PyCharm — пометь корень как **Sources Root**.

### `selenium.common.exceptions.WebDriverException`
ChromeDriver не найден или его версия не совпадает с Chrome. Скачай актуальный.

### `TimeoutException` при получении координат
Яндекс мог изменить вёрстку или ограничить автоматический доступ. Увеличь таймаут в `route_calculator.py` (`WebDriverWait(self.driver, 10)`).

### Адрес не найден
Программа пропустит его с сообщением в консоли. Проверь, что адрес корректен и существует в указанном городе.

### Окно tkinter не открывается на Windows
Python установлен без `tcl/tk`. Переустанови с [python.org](https://www.python.org/downloads/), поставив галочку **«tcl/tk and IDLE»**.
